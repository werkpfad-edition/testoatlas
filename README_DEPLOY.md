# TESTOATLAS – Website V1

Statische, uploadfertige Website ohne Build-System.

## Vor Livegang noch einzutragen
1. `impressum.html`: Betreiber, Anschrift, Kontakt.
2. Shop-Links in `buch.html`, sobald epubli/Tolino/Amazon URLs vorliegen.
3. Domain ist gesetzt: `https://testoatlas.de`. `CNAME`, `sitemap.xml` und `robots.txt` sind vorbereitet.
4. Optional später Google Search Console und datenschutzkonformes Analytics ergänzen.

## Dateien
- `index.html` Startseite
- `blutwerte.html` interaktiver Blutwerte-Erklärer
- `umrechner.html` Testosteron-Einheitenrechner
- `testosteronmangel.html` Differentialdiagnostik / Doppelgänger
- `trt.html` TRT
- `fruchtbarkeit.html` Fertilität
- `muskelaufbau.html` Training / Enhancement
- `buch.html` Buch-Landingpage
- `ueber.html`, `quellen.html`, `impressum.html`, `datenschutz.html`

Die Rechner arbeiten vollständig clientseitig.
